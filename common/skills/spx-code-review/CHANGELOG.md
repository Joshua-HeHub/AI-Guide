# 变更日志

本文件仅记录 `spx-code-review` skill 的版本变更，不管理插件版本。版本范围包括入口、审查清单、报告模板、示例及其他随附资源；当前版本以 [SKILL.md](./SKILL.md) 中的 `metadata.version` 为准。

版本按新到旧排列。未定版的变更先记录到 `Unreleased`，定版时归入对应版本和日期，并同步更新 `metadata.version`。

## [Unreleased]

暂无待定版变更。

## [1.0.1] - 2026-10-16

### 精简与收敛

- SKILL.md「不可省略的规则」由 14 条收敛为 5 条：提交材料、Sensor、IPMI 权限、北向审计、散热等判定细节收归必须加载文件与对应专项清单，删除规则区与 Step 5 之间的重复表述。
- 删除 spx-project-checklist 中与 SKILL.md「按场景加载」重复的基础路由表，改为指向 SKILL.md 单一来源。
- Review 事项汇总的 `V`/`X` 标记与关联项填写规则收归报告模板单源；`review-policy.md` 约束 8 改为引用模板，保留专项强制提示不变式。
- 新增「四要素」代币（代码位置、判定依据、可能后果、实际缺失材料），定义于报告模板，替换原先分散多处、措辞各异的风险说明要求。
- description 改写为人类向摘要；调用方式保持 `disable-model-invocation: true` 不变。

### 兼容性说明

- 审查契约不变：全部检查领域、强制 `X`、风险确认与交叉验证要求原样保留，仅调整其权威定义位置。

## [1.0.0] - 2026-10-15

首次建立独立版本基线。以下记录基线已包含的主要内容，不追溯或虚构此前未编号的版本。

### 新增

- 使用 `metadata.version` 标识 skill 自身版本，初始版本为 `1.0.0`。
- 提供独立变更日志，并在入口中添加按需查看的相对链接。
- 默认手动调用，保留 `disable-model-invocation: true`。
- 固定输出 24 个检查领域，保留三态、`V`/`X` 标记及问题和风险确认的关联。

### 修正与澄清

- 修正 `strlen()` 长度赋给 `int` 后负值判断的错误说明，增加以 `size_t` 保存长度、转换前检查 `INT_MAX` 的示例。
- 统一提交材料缺失时的汇总状态：标记为“当前项有风险”、填写 `X` 并关联 `风险确认 #N`；“待提供”“未检查”仅表示证据进度。
- 区分“证据缺口”和“专项强制提示”，同步报告模板、示例、审查入口和专项清单。
- 保留 BMC 升级/系统内部文件变更，以及 IPMI 权限变更命中调用方时的专项强制 `X`；材料齐全也不自动转为 `V`，且不得虚构材料缺口或代码缺陷。
- 明确普通证据缺口的关闭条件：关联汇总项的全部问题和风险关闭，且未命中专项强制提示时，才可改为 `V`。

### 兼容性说明

- 本版作为初始基线，无已编号旧版本的迁移要求。
- 保留 SPX 专用规范、完整汇总表及 Sensor 等专项强检查要求。
- 本日志用于版本追溯，不作为每次代码审查的必读材料。

## 后续维护约定

- `PATCH`：修正文案、示例或歧义，不改变现有审查契约。
- `MINOR`：新增向后兼容的能力，例如可选检查或辅助示例。
- `MAJOR`：不兼容地改变强制输出字段、风险门禁、调用方式或已有规则语义。
- 每次定版记录日期、变更摘要及兼容性影响；涉及不兼容变化时补充迁移说明。
- 已定版条目保持可追溯；后续行为变化记入新版本，不回写成旧版已有行为。
