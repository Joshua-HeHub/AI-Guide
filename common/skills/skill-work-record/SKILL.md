# Work Record

## 目标与入口

将已获用户授权的工作摘要写入指定在线工作簿，回读并确认云端保存。
本技能位于个人技能目录，可跨工作区使用。

- 默认工作簿：[工作内容记录表.xlsx](https://inventeccorp-my.sharepoint.com/personal/he_joshua_inventec_com/_layouts/15/Doc.aspx?sourcedoc=%7BCCE9AEE1-3968-4358-9127-44FDB695C9F5%7D&action=default)。用户已确认该链接可保留；它不包含登录凭据。
- 用户本轮提供的链接优先；有已共享同一工作簿页面时直接复用，不依赖旧 page ID。
- 默认页签由用户指定；常见项目页签是 `P9500AG7` 和 `Poyanghu`。每次读取实际页签和表头后再决定位置。
- 用户说“工作记录表”时优先使用在线工作簿；只有明确要求本地执行日志时才创建过程文件。
- 不自动新建 Track/Redmine、修改代码、提交 Git 或操作机台。

## 执行预算与能力门禁

先准备完整字段，再操作工作簿。正常路径按四个阶段批量执行：预检、基线、写入回读、保存重开核验；不是每格一次工具调用。

1. 首次预检同时核实工作簿身份、可见 frame、编辑态和剪贴板写入能力（`writeText`），不要求 `readText` 权限。
2. 旧页面不可用时最多重开一次；新页面仍不可交互就停止，不持续强制点击。
3. 剪贴板写入探测失败立即返回 `CLIPBOARD_UNAVAILABLE`，不进入逐格输入循环。
4. 已执行写入但回读不匹配时停止，保留现场；下次先回读，不能盲目再追加。

脚本默认剪贴板探测预算 1500ms、定位/回读 3000ms、保存标记 5000ms。这些是操作超时，不是网络或端到端耗时保证。支持的官方工作簿 API 只有在认证和权限已验证后才可替换 UI 路径；不自动申请权限或整本覆盖上传。

## 执行流程

### 1. 定位与基线

1. 加载浏览器工具，打开或复用用户指定的工作簿；`preflight(page)` 通过后才进入写入准备。登录或 MFA 由用户直接在浏览器完成。
2. 确认工作簿标题/身份、可编辑状态和目标页签。通过名称框角色发现 frame，不依赖 frame URL；确认没有用户正在编辑的单元格。
3. 一次读取表头、相邻已有记录和候选空行作为基线。新记录使用下一空行；相同日期和工作内容已存在时更新原行，防止重复登记。
4. 确认目标行各列无其他记录；多用户编辑有冲突时停止覆盖，只询问冲突项。

当前已验证的常见表头：

| 列 | 含义 | 写入规则 |
| --- | --- | --- |
| B | 开始日期 | 实际工作日期，不因补录自动改成当前日期 |
| C | 状态 | 按用户决定及表内约定，如完成、进行中、遗留 |
| D | 描述 | 一两句工作对象与现象，避免塞入整段分析 |
| E | Redmine | 有真实编号再填，无编号留空 |
| F | 结束日期 | 实际结束才填；遗留或进行中留空 |
| G | 处理结果 | 已确认机制、处理动作或当前结论 |
| H | 备注 | 用户反馈、待确认差异及后续动作 |

表头是运行时事实；先验证，后写入。

### 2. 准备内容

- 区分本机已验证事实、用户反馈和未验证推断。源码相同或版本号相同不等于两台机器运行数据相同。
- “SIT 正常”记为用户反馈或实测来源；“估计问题不大”记为暂缓处理决定，不扩大成无风险结论。
- 遗留问题保留待确认事项，不写成已修复、已关闭，也不编造结束日期。
- “研究完成”可以登记为完成，但必须与“缺陷已修复”区分；已知硬件问题写明来源及本次是否修复。
- 详细日志、调用链、行号保留在分析材料，工作表写简短结论。
- 按实际表头构造单行字段数组，空列保留空字符串。写为值；内容以 `=`, `+`, `-`, `@` 开头时先按文本处理，避免公式注入。
- 多行描述或字段内含制表符时，优先使用经过验证的 Excel 剪贴板格式或逐格写入；普通 TSV 模板只用于无内嵌换行和制表符的单行字段。

### 3. 批量写入与立即回读

操作实现仅维护在 [excel_online_ops.js](./scripts/excel_online_ops.js)。代码支持 CommonJS 导出，供本地 Playwright 适配器与离线测试加载。集成浏览器工具若不能访问远端模块，读取该文件后，将需要的定义和调用组成一个自包含代码片段；不假定工具已自动加载这些函数。

- `preflight(page)`：按可见名称框定位唯一工作簿，排除活动编辑，验证 `excelFrame`/`page` 剪贴板写入（`writeText`）可用。
- `selectRangeByNameBox(page, targetRange, options)`：定位并等待目标范围出现在网格辅助功能名称中。
- `pasteTsvRow(page, fields, {targetRange, sheetTabName})`：校验单行范围宽度、目标页签和能力，在焦点 `excelFrame` 写剪贴板 TSV + `Control+v` 整行分列粘贴，随即逐格通过公式栏回读；空列传 `''`。
- `readbackSelection(page, expectedFields, {targetRange})`：用名称框依次定位目标行各列并读取 `formula bar` 的 `innerText()`，无需 `clipboard-read` 权限，精确保留空列。
- `waitForSaved(page)`：核实保存标记；返回的 `persistedAfterReload` 仍为 false，需重开回读后才能确认持久化。

所有函数均无自动重试循环。脚本返回值使用 `return`；权限提示、空结果、等待返回 false、粘贴事件被接收均不算成功证据。

### 4. 保存与重开核验

1. 等“正在保存”消失，并确认“已保存”或“上次保存时间”；仅粘贴成功不算保存完成。
2. 刷新或重开一次，等初始化完成，重新定位同一页签和选区，批量回读全部目标列。
3. 对比基线：原有相邻记录未变、结束日期及编号空列正确、目标区外没有错位文字，才结束。
4. 简短交付：工作簿链接、页签和行号、状态、持久化核验结果；不重述完整分析。

## 已验证的故障信号

- 旧页面 frame URL 为空，按 URL 查找失败；名称框角色仍可发现工作簿。页面交互失效与 URL 缺失不是同一事实。
- `commit edit` 按钮可见但带 `button-disabled` 时并非活动编辑；不能只检查 `isVisible()`。
- 跨域 `excelFrame` 下 `navigator.clipboard.writeText()` + `Control+v` 可正常整行粘贴，但 `clipboard.readText()` 常报 `Read permission denied`（或在顶层 `page` 无焦点时返回空串）。禁止把 `readText()` 作为预检阻断条件；统一用 `excelFrame.evaluate(writeText)` 粘贴 + 名称框/公式栏 `innerText()` 回读。
- 普通中文输入、公式栏 fill、F2/insertText、合成粘贴事件均曾未落盘；不轮流重试这些方法，也不把事件被处理当成服务器保存。
- 页面包含不可见的加载/断网提示模板；对全部 DOM 做文本搜索不能证明实际断网，应看可见状态或明确网络错误。
- Playwright 的 `deferredResultId` 用同一 `run_playwright_code` 恢复，不能传给终端输出工具。

## 脚本检查

使用 Node 内置测试，不连接在线工作簿：

```bash
node --test ~/.copilot/skills/skill-work-record/scripts/excel_online_ops.test.cjs
```

离线测试只验证保护逻辑；浏览器端到端写入与刷新回读仍需实际成功证据。

## 完成标准

- 指定工作簿、正确项目页签、正确目标行。
- 全部目标单元格逐格匹配，未覆盖相邻记录。
- 已确认云端保存，刷新后内容仍一致。
- 结论、用户反馈和待验证项分开，未增加未经授权的外部操作。
