# 会话收尾统一入口

本文件只做调度，不重复任何手册内容。三份手册按需读取并照其步骤执行。

## 调度规则

开始后先用一句话向用户确认执行范围：三段全做（默认）、或用户点名只做某段。每段完成后给出该段结论并等用户放行，再进入下一段；用户喊停即停。

| 段 | 读取并执行 | 消费 | 产出 |
|----|-----------|------|------|
| 1 行为复盘 | `retro/SKILL.md` | 本会话（或用户指定的历史会话）记录 | 环境改进候选清单（按严重度排序，经用户挑选才执行） |
| 2 知识对账 | `neat-freak/SKILL.md` | 代码/配置现状 vs project docs 与 agent 记忆 | 修正后的文档与记忆（每处修改立即读回验证） |
| 3 交接快照 | `skill-handoff/SKILL.md` | 阶段 2 修正后的最终状态 | 可直接粘贴到新 chat 的接续上下文 |

## 顺序与跳过

- 默认顺序不可倒置：复盘发现的知识遗漏应先在段 2 修正，交接快照才反映真实状态。
- 用户只要后段时跳过前段，不必补跑。

## 硬约束

- 全程遵守 `.github/memories/execution-discipline.md`（中文回答、未验证标注、决策用弹框、终端命令记日志）。
- 段 2 修改 skill/指令文件时，注意 VSC_guide 硬链接拓扑（编辑即同步 common；上游镜像由 skill-sync-guide 单独对账）。
- 阶段 1 的候选只有用户确认后才落盘执行；不得自行挑选全部实施。
