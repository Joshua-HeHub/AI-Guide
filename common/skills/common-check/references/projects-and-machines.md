### 只读比较方式

先将 `repo`、`remote`、`branch`、`commit` 和 `path` 绑定为本轮已确认值，再使用以下命令形式。 shell 调用仍须经工作区日志包装，并优先使用 `rtk proxy`。

```bash
git -C "$repo" status --short --branch
git -C "$repo" rev-parse --show-toplevel
git -C "$repo" ls-remote --heads "$remote" "refs/heads/$branch"
git -C "$repo" show "$commit:$path"
git -C "$repo" grep -n -E "$pattern" "$commit" -- "$path"
```

本地缺少对象时，可只获取目标分支对象：

```bash
git -C "$repo" fetch --no-tags --no-recurse-submodules --no-write-fetch-head "$remote" "refs/heads/$branch"
```

该命令写入本地 Git 对象库，不切换分支、不改工作树；完成后仍按明确的提交号读取。远端分支若在核查期间移动，以实际取得的提交重核基线。

分支映射与 Gerrit 取证细节：`/memories/repo/gerrit-change-fetch.md`。
